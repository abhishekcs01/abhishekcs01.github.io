## 🔧 Deployment
This site is live via **GitHub Pages**. To deploy:
1. Clone the repository:
   ```bash

2. Make edits as needed and push to main branch.
3. Ensure GitHub Pages is enabled in Settings → Pages → Source = Deploy from branch.
